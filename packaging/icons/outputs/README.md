# Output icons

ADR-0361: the icons an output can be given, named as the protocol names
them (`outputs.configure {icon}`). Each is a Lucide icon (lucide-static
1.70.0), copied unchanged and renamed:

| Name | Lucide icon |
|---|---|
| speaker | speaker |
| headphones | headphones |
| tv | tv |
| computer | monitor |
| laptop | laptop |
| phone | smartphone |
| car | car |
| radio | radio |
| living-room | sofa |
| kitchen | chef-hat |
| bath | bath |
| bedroom | bed-double |
| office | briefcase |
| garden | tree-pine |
| music | music |

Lucide is under the ISC license, in `LICENSE-lucide`. The icons are drawn in
`currentColor`; Melody draws them in its palette's text colour.
